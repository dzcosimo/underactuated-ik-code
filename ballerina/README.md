# Ballerina on an elastic pointe

A planar dancer balancing on one pointe. The pointe is a passive torsional spring with a damper; the hips and the shoulder are actuated. The task is the position of the centre of mass (CoM). With three actuators and a two-dimensional task the inversion is redundant, so both algorithms use a pseudoinverse.

## System

Parameters in `src/bal_params.m`. Configuration `q = (qa1, qa2, qa3, qu)`, angles positive clockwise:

| Coordinate | Joint | Actuated |
|---|---|---|
| `qa1` | torso relative to the stance leg (hip) | yes |
| `qa2` | working leg relative to the stance leg (hip) | yes |
| `qa3` | arm relative to the torso (shoulder) | yes |
| `qu` | stance leg at the pointe, from vertical | no: spring `k`, damper `b` |

Bodies are uniform rods (stance leg 0.9 m, torso 0.6 m, working leg 0.9 m, arm 0.55 m) with a point-mass head; total mass 13.2 kg. Pointe stiffness `k = 200` Nm/rad (`ksoft = 120` for the soft scenario), damper `b = 50` Nms/rad. Low-level controller `tau = G_a(q_bar) + P (qa_bar - qa) - D qa'`, `P = 300 I`, `D = 30 I`.

The passive statics is `G_u = k qu - M g x_c = 0` (spring torque against the gravity torque of the CoM about the pointe). It is stable when `H_uu = k - M g z_c > 0`.

The model functions in `model/` are generated by `model/gen_symbolic.m` (Symbolic Math Toolbox) and shipped, so the toolbox is needed only after a change of `bal_params.m`.

## Algorithms

Notation: `H` potential Hessian, `[Ja Ju]` CoM Jacobian, `X = H_uu^-1 H_ua`, `J = Ja - Ju X` (task Jacobian along the equilibrium set).

- Algorithm 1: `qa_bar' = J^+ Gam e`, `qu_bar = phi(qa_bar)` from Newton on `G_u = 0` (`src/bal_phi.m`).
- Algorithm 2, non-square generalization: with `T = [I; -X]`, `Y = Ja^+ Ju`,
  `q_bar' = T J^+ Gam e - [-Y; 1] (H_uu - H_ua Y)^-1 Gp G_u(q_bar)`.
  The first term moves along the tangent of the equilibrium set and changes only the task; the second leaves the task unchanged to first order and drives `G_u` to zero. With a square, invertible `Ja` the two terms reduce to the `P_E Ja^-1` and `P_Z H_uu^-1` terms of the paper.

`J^+` is the plain Moore-Penrose pseudoinverse. The CLIK velocity is saturated at 1 rad/s per component (`src/bal_sat.m`; clipping by default, `satmode = 'scale'` scales the vector instead).

## Scenarios

Defined in `src/bal_scenario.m`. The CoM visits three targets: T1 arabesque penchée (CoM forward, lowered), T2 centred and raised, T3 cambré to the other side. The first target is a step; afterwards the reference slides linearly to the next target in 3 s and holds it (6 s per target, 18 s in total). Start and targets were chosen by kinematic screening (foot clearance, arm elevation, smallest singular value of `J`, `H_uu` margin). Task gain `Gam = 3` in feedforward, `1` in feedback, where the measured CoM includes the slow sway of the pointe. Statics gain `Gp = 3`; Algorithm 2 starts with `qu_bar` offset by 0.15 rad from the equilibrium set.

| Set | Runs | Setting |
|---|---|---|
| `main` | `a1ff`, `a1fb`, `a2ff`, `a2fb` | nominal: plant and model with `k = 200` |
| `mismatch` | `a2ff`, `a2fb` | plant `k = 200`, CLIK model and low-level controller `0.8 k = 160` |
| `soft` | `a2ff` | plant and model with `k = 120`; start at rest at the stable T1 equilibrium of this stiffness, then slide to T2, which is an unstable equilibrium here. The start `qa0` comes from a continuation `k = 200 -> 120` of the Algorithm 1 flow at T1. |
